# Book Club

The family book club: one club reads one current book, keeps a history book for it, and talks about it in comments.

## Language

**Current book**:
The book the club is reading now.
_Avoid_: active book

**History book**:
The club's stored record of a book.
_Avoid_: archive entry

**Past book**:
A history book that is not the current book. The screen is labeled Past books.
_Avoid_: Already read. That phrase is the status shown when a listed book cannot be chosen.

**Comment**:
A member's written remark on a history book.
_Avoid_: note, personal note
